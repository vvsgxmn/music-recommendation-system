# 基于SpringBoot+Vue的音乐推荐系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![ElementPlus](https://img.shields.io/badge/-ElementPlus-grey?style=flat-square) 

## 项目介绍

这是一个功能完善的音乐推荐系统，采用前后端分离架构开发，集成了多种推荐算法（协同过滤、基于内容推荐、UserCF），为用户提供个性化的音乐推荐体验。系统分为用户端和管理后台两个模块。

### 功能模块

- **首页热门推荐**：展示热门音乐，支持轮播图、音乐分类筛选（语言/风格）
- **个性化推荐**：基于协同过滤和内容推荐算法，为用户智能推荐音乐
- **我的收藏**：用户可收藏喜欢的音乐，支持播放和批量操作
- **我的歌单**：支持创建、编辑、删除自定义歌单
- **播放历史**：记录用户播放历史，展示播放次数和最后播放时间
- **听歌报告**：展示用户听歌数据统计
- **管理后台**：数据概览仪表盘、音乐管理（CRUD）、用户管理、标签管理

### 技术架构

- **后端**：Spring Boot 2.7.18 + MyBatis 2.3 + Spring Security + Redis
- **前端**：Vue 3.3 + Element Plus 2.4 + Vite 4 + ECharts 6 + Pinia
- **数据库**：MySQL 8.0
